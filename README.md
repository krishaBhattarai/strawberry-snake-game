# 🎀 Strawberry Snake Game 🍓🐍

A cute aesthetic Snake Game built using Python and Pygame.

## ✨ Features

🎀 Girly pink UI theme  
🐍 Light blue snake design  
🍓 Strawberry food system  
👤 Player profile system  
🏆 High score saving  
🌸 Three difficulty levels  
🧱 Custom brick border  
🎮 Keyboard controls  

## 🛠️ Technologies Used

- Python
- Pygame
- Object-Oriented Programming
